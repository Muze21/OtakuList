# Anime Tracker App (MyAnimeList-style)

A personal Flutter project inspired by MyAnimeList.
Built for learning purposes and gradual feature development.

## Status
🚧 Work in progress  
This project is still under active development.  
Features, structure, and UI may change anytime.

## Goals
- Practice Flutter with Clean Architecture
- Learn authentication & backend integration (Supabase)
- Build an anime tracking app (watchlist, ratings, reviews)

## Tech Stack
- Flutter
- Dart
- Supabase
- Freezed & Json Serializable
- Clean Architecture (data / domain / presentation)

## Current Progress
- Project structure setup
- Authentication (login & register)
- Basic models & entities
- Supabase integration (ongoing)

## Planned Features
- Anime list & detail page
- User watchlist
- Rating & review system
- Profile management

## Notes
This repository is mainly used for learning and experimentation.
Not intended for production (yet).
